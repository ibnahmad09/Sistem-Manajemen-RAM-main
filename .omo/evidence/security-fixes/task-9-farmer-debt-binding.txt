Task 9: FarmerDebt — fix implicit binding + dangling transaction
=================================================================
Date: 2026-09-13
Branch: Fix-Security
Status: DONE

ROOT CAUSE
----------
Route::resource('debts', ...) (routes/web.php:73-74) generates route param
{debt} for show/destroy. Controller signatures used $farmerDebt
(FarmerDebtController.php:124/134) which does NOT match {debt} -> implicit
route model binding skipped -> fresh empty FarmerDebt model -> fatal Error
(not Exception) -> HTTP 500 + DB::beginTransaction() in destroy() left
dangling (never rolled back because fatal Error bypasses catch \Exception)
-> poisons subsequent requests (PoC-A+B).

FIX
---
app/Http/Controllers/FarmerDebtController.php:
- show(FarmerDebt $farmerDebt)  -> show(FarmerDebt $debt)   (line 124)
- destroy(FarmerDebt $farmerDebt) -> destroy(FarmerDebt $debt) (line 134)
- All body references renamed $farmerDebt -> $debt (load, json, farmer, delete)
- DB::rollBack() in catch block (line 151) verified PRESENT and unchanged
- grep: 0 remaining references to $farmerDebt
